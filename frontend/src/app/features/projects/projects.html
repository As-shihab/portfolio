Founder

Aptigen ERP

"The operating system for modern business."

I started Aptigen because I kept seeing businesses run on spreadsheets and tools that don't talk to each other. Aptigen puts HR, sales, accounting, inventory and day-to-day operations into one system.

It has 21 connected modules on a single live data layer, so a sale, a stock change or a new hire shows up everywhere at once. It runs on the web, on desktop (Windows, Mac and Linux) with offline support, and on mobile. Retail shops, restaurants and hotels use it, including businesses with more than one location.

Visit aptigen.net Try the live demo

The store module also connects to the B2B marketplace. Based in Gulshan, Dhaka.
